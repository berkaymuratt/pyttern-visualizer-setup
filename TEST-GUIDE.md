# Usability Test — Task File Guide

> The tasks and questions are hosted on the **INGInious** platform. This document is a quick reference for finding the files you need during the test.

---

## Overview

You will use the **Pyttern Visualizer** to analyze Python student submissions against compound patterns. There are two tasks. Each task gives you:

- A set of `.pyt` **pattern files** to build a compound pattern with.
- A set of **student code files** to upload and analyze.

If you are unfamiliar with what a compound pattern is or how to build one as a folder structure, see: **[Compound Pattern Guide](compound-pattern-guide.md)**

---

| Folder | Contents |
|--------|----------|
| `Task_A/pyttern_files/` | The `.pyt` pattern files for Task A |
| `Task_A/student_submissons/` | The 5 student Python files to upload |

| Folder | Contents |

## Quick Checklist

1. Start the Pyttern Visualizer — if you don't setup yet, see [README.md](README.md) for setup instructions.
2. Open `http://localhost:5173/` in your browser.
3. Follow the **Task A** instructions on INGInious, using the files in `Task_A/`.
4. Follow the **Task B** instructions on INGInious, using the files in `Task_B/`.
5. Complete the **Feedbacks** task for your feedbacks.

Thank you for your attendance and feedbacks!
